# Showcase theo đợt

Mỗi đợt B2/B3: `docs/showcase/<đợt>/` gồm ảnh + video 30–60 s + `checklist.md` để Duy chấm từng hạng mục (giữ / sửa / bỏ).

Video lớn (> 5 MB) không commit: lưu ngoài repo, `checklist.md` ghi đường dẫn local + SHA-256. Ảnh nén WebP/JPEG ≤ 500 KB mỗi ảnh.
Không đưa ảnh cá nhân của Duy vào đây (chỉ ảnh render từ engine/Blender).
